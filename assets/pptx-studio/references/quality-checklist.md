# 质量检查清单

`pptx_check` 会自动给出几何检查结果。下表中标"自动"的由工具检查；其余由你逐页核对。

## 内容

- [ ] 页数与大纲一致；封面、目录（多于 8 页时）、章节页、结尾页齐全。
- [ ] 每页标题是结论句，标题依次读下来能讲完整个故事。
- [ ] 文字量不超过所选等级的上限（自动：按字数统计）。
- [ ] 数据、名称、日期与用户提供的材料一致，没有编造的数字。
- [ ] 名画、文物、地标、名人、产品等已知对象使用真实素材（注明来源与许可），没有用 AI 臆造代替。
- [ ] 投影可读性：压在纹样/图片上的文字面板不透明度 ≥0.95；正文 ≥16–17pt；细字不直接压在暗纹上；三列边缘有足够间距（≥3%）。
- [ ] 演讲者备注符合文字量等级的要求。

## 版面

- [ ] 文字没有溢出文本框（自动）。
- [ ] 元素之间不重叠，装饰除外（自动）。
- [ ] 所有内容元素都在安全区内（自动）。
- [ ] 字号不低于对应角色的最小字号（自动）。
- [ ] 内容覆盖率达标（自动：`pptx_check` 的 `fill` 检查，按复杂度 25/35/45/55/60%；封面、章节、结尾、引言、全图页不查）。
- [ ] 没有超过 1/4 页的空白带；空白只出现在单侧、段落之间或图片周围。
- [ ] 字多时图少（双栏/表格/卡片铺满），字少时图多（配图/大数字/大字号撑满）。
- [ ] 标题加粗放大（内容页 36–44pt、封面 display 52–60pt），统一左对齐（刻意居中的版式除外）；数字用特大号 + 小一号单位；卡片铺到接近 x6–94 / y24–88，没有为了塞内容缩小字号。
- [ ] 版心统一：标题与正文左边缘一致（x 6–8），卡片顶部一致、间距相等；只有 quote、image-full、banner 竖排这类刻意居中的版式才居中。
- [ ] 信息 ≤6 项已卡片化（图标 + 浅灰标签 + 加粗数据）；必须用表格时是轻量样式——细浅线、zebra 隔行、数字加粗、首列居中，没有粗黑外框。
- [ ] 底部不使用与内容脱节的通栏大色块；收尾条与上方内容留 2–3% 间距、宽度与内容区对齐。
- [ ] 每页只有一个视觉焦点。

## 视觉

- [ ] 文字与其底色的对比度：正文 ≥ 4.5:1，大标题 ≥ 3:1（自动：按 deck.json 中声明的底色计算；背景图上的文字需要视觉检查）。
- [ ] 背景图的文字区干净，没有装饰压住文字（自动：`pptx_check` 会对图片背景上的文字框采样，报告对比度不足和装饰穿过文字框的比例）。出现这类问题时，把文字框往内收、给文字加一块 `shape` 或 `panel` 衬底，或者重新生成背景并在构图里扩大留白。
- [ ] 背景里没有烘焙进装饰件：没有角的枝条、徽章、飘带、散落星点、道具；背景只该有质感、光和主体。
- [ ] 装饰件边缘干净：透明、没有白边或黑边、没有残底、没有被切坏、主体没有被裁。
- [ ] `sheet` 模式的件名与 subject 对得上、件数对：对不上时重新生成，或把该组改成 `mode: "single"`。
- [ ] 同一件装饰在整套里复用（镜像、旋转、缩放），风格与背景一致；同一组 kit 来自同一张整版图或同一套 styleAnchor 的逐件生成，跨组也像同一套。
- [ ] 装饰件数量符合复杂度（自动：`pptx_check` 按 `DECOR_PER_SLIDE` 检查每页件数，`image-full` 页不查下限）。
- [ ] 装饰件不压文字、不压饰板，也没有被压扁（圆形件仍是圆的；`decor` 的 box 是百分比，图片按物理比例缩放）；右下角页码饰牌附近不放装饰件（自动：`pptx_check` 报告写在文字之后且盖住文字的装饰；压扁、压饰板仍需目检）。
- [ ] 四角装饰对称：同一件的镜像，方向与大小一致；四角都有件时不要缺角。
- [ ] 所有图片风格一致：色调、画风、细节密度相同。
- [ ] 图片里没有文字、乱码、水印或 logo。
- [ ] 插画是 `cutout` 透明 PNG，直接放在背景上：没有白框/白边，也没有用 `panel` 包住插图；主体内部的白色（白衬衫、机器人外壳、屏幕）没有被抠掉。
- [ ] 旧 `onColor` 插画的底色与所在位置的底色一致，没有明显的方框边缘（cutout 插画不存在这一项）。
- [ ] 颜色只使用主题色；accent 每页最多一两处。
- [ ] 复杂度符合所选等级：装饰数量、配图数量与 [complexity.md](complexity.md) 一致。
- [ ] 华丽档：背景是同色系满版底纹、中间低对比；装饰件铺满页面边缘与四角；所有文字都在饰板上；饰板没有盖住背景的主视觉。

## 修正优先级

1. 内容错误（数据、事实）。
2. 文字溢出、遮挡。
3. 图片中的文字或乱码。
4. 风格不一致的图片。
5. 对齐与间距。

改文字优先于改字号；改字号不得低于最小字号；图片问题只重新生成有问题的那一张。
